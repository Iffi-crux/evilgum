Architecture

Put safety on the wire. Nothing else about your agent changes.

MCP lets AI agents run real tools — read files, query databases, execute code. EvilGum sits between your agent and the tools, ensuring zero unauthorized actions occur.

1

Authenticate

Verifies agent identity via asymmetric JWTs (RS256/ES256) or HMAC macaroons before processing tool requests.

2

Authorize & Scope

Enforces strict per-tool RBAC policies. Agents can only execute tools explicitly granted to their role.

3

Track Taint

If an agent reads untrusted data (web pages, user files), the session is marked TAINTED, blocking dangerous sinks.

4

Sanitize & DLP

Scans tool output for PII (SSNs, API Keys, Credit Cards) and redacts sensitive data before returning to the model.
